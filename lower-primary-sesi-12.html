Rigo memakai loop untuk cerita baru

Sesi 12 melanjutkan ide dari Kincir Angin. Repeat tetap dipakai, tetapi aksi di dalamnya sekarang adalah Grow, bukan Turn Right.

Rigo ingin membuat animasi sederhana yang menunjukkan tabungan bertambah. Karena itu Koin akan dibuat membesar lima kali.

Setelah animasi selesai, project menampilkan pesan “Tabunganku bertambah”.

Empat tujuan utama

Siswa mengenal numbered loop, memahami Grow, menghubungkan animasi dengan cerita menabung, lalu membuat project Bunga Tabungan.

Testing juga menjadi bagian penting. Siswa akan mencoba jumlah Repeat yang berbeda untuk melihat dampaknya secara langsung.

Materi tidak meminta perhitungan bunga bank. Fokus financial literacy-nya adalah kebiasaan menabung dan ide bahwa tabungan dapat bertambah.

Konsep yang sama, aksi yang berbeda

Di Sesi 11, Repeat berisi Turn Right. Di Sesi 12, Repeat berisi Grow. Ini menunjukkan bahwa Repeat bukan hanya untuk gerakan berputar.

Selama sebuah aksi ditempatkan di dalam Repeat, aksi tersebut dapat dijalankan sesuai jumlah pengulangannya.

Hubungan antarsesi ini membantu siswa melihat bahwa konsep coding bisa dipakai kembali pada project yang berbeda.

Numbered loop adalah Repeat dengan jumlah

Materi menyebutnya numbered loop: kita menentukan sendiri jumlah pengulangannya. Repeat 5 berarti isi Repeat dijalankan lima kali.

Angka Repeat tidak menunjukkan ukuran sprite. Angka ini hanya menunjukkan berapa kali aksi di dalamnya dijalankan.

Nanti perbedaan ini penting saat membandingkan Repeat dengan Grow.

Grow membuat sprite membesar

Screenshot di slide kiri menunjukkan block Grow asli. Fungsi Grow adalah membuat sprite terlihat lebih besar.

Materi memberi contoh bahwa Grow bisa digunakan untuk koin, tanaman, atau benda lain. Pada project ini, kita menggunakan sprite Koin.

Satu Grow adalah satu aksi. Kalau ingin Grow terjadi beberapa kali, kita memasukkannya ke Repeat.

Jangan tertukar: Repeat bukan Grow

Repeat menjawab “berapa kali?”, sedangkan Grow menjawab “aksi apa yang dilakukan?”. Jadi Repeat 5 [Grow] berarti lakukan aksi Grow lima kali.

Materi juga menegaskan bahwa angka pada Grow dan angka pada Repeat punya fungsi berbeda. Siswa cukup memahami perbedaan tugasnya, tanpa perlu perhitungan rumit.

Kalimat pengingat: Repeat = berapa kali, Grow = menjadi lebih besar.

Aktivitas kecil, sedang, besar

Aktivitas menggambar tiga koin membantu siswa melihat perubahan ukuran sebelum masuk ke coding.

Koin dari kecil ke besar bisa dibayangkan sebagai hasil beberapa aksi Grow. Kalau Grow diulang lebih banyak, perubahan ukuran terlihat lebih banyak.

Aktivitas ini tidak menggunakan uang asli. Ini hanya model visual untuk memahami Grow dan Repeat.

Konteks menabung dibuat sederhana

Menabung berarti menyisihkan uang untuk disimpan. Materi menyebut bahwa pada tabungan tertentu di bank ada tambahan kecil yang disebut bunga.

Namun project tidak menghitung bunga dan ukuran Koin tidak sama dengan jumlah uang sebenarnya. Koin membesar hanya simbol visual bahwa tabungan bertambah.

Gunakan data latihan dan jangan memasukkan data finansial pribadi ke project.

Empat block dan fungsinya

Green Flag memulai project. Repeat mengatur jumlah pengulangan. Grow membuat sprite membesar. Say menampilkan dialog.

Screenshot block membantu siswa mencocokkan bentuk block asli di ScratchJr. Ini lebih mudah daripada hanya menghafal nama block.

Urutan block akan menentukan urutan kejadian dalam animasi.

Starter project sudah punya Koin

File starter membuat siswa tidak perlu menggambar seluruh project dari awal. Setelah dibuka, pilih sprite Koin dan masuk ke Code Area.

Fokus utama adalah menyusun block sesuai misi dan menguji hasilnya.

Jika project belum terbuka dengan benar, selesaikan masalah file terlebih dahulu sebelum mulai coding.

Sequence membuat cerita masuk akal

Project perlu berjalan dalam urutan yang jelas: mulai, Koin membesar, lalu dialog muncul.

Grow berada di dalam Repeat karena kita ingin aksi Grow terjadi lima kali. Say berada setelah Repeat karena kita ingin pesan muncul sesudah animasi selesai.

Kalau posisi Say diubah, hasil cerita juga berubah. Inilah hubungan antara urutan block dan output.

Mulai dari event

Green Flag adalah titik awal script. Saat bendera ditekan, ScratchJr menjalankan block setelahnya dari kiri ke kanan.

Biasakan siswa mengecek event ini terlebih dahulu saat project tidak bergerak.

Membangun rangkaian secara bertahap membuat siswa lebih mudah memahami fungsi setiap block.

Grow harus masuk ke Repeat

Screenshot final menunjukkan Repeat bernilai 5 dengan Grow berada di dalamnya. Itu berarti Grow dijalankan lima kali.

Jika Grow berada setelah Repeat, Repeat tidak mengulang Grow. Hasilnya Koin hanya akan membesar sekali ketika block Grow dijalankan.

Ini salah satu titik debugging utama dalam materi Sesi 12.

Say berada setelah loop

Block Say digunakan untuk membuat percakapan. Teks project adalah “Tabunganku bertambah”.

Say berada setelah Repeat supaya dialog muncul satu kali ketika animasi Grow sudah selesai. Jika Say dimasukkan ke dalam Repeat, dialog akan ikut dijalankan berulang.

Ini membantu siswa memahami bahwa posisi block memengaruhi kapan sesuatu terjadi.

Membaca script tanpa menebak

Baca rangkaian dari kiri ke kanan: Green Flag memulai, Repeat 5 mengulang Grow, kemudian Say menampilkan pesan.

Dengan membacanya sebagai kalimat, siswa bisa menjelaskan apa yang dilakukan program sebelum menekan Green Flag.

Kemampuan memprediksi output adalah bagian penting dari belajar coding, bukan hanya meniru rangkaian block.

Testing dengan jumlah berbeda

Materi secara khusus meminta siswa memikirkan Repeat 2 dan Repeat 8. Repeat 2 menjalankan Grow lebih sedikit daripada Repeat 5. Repeat 8 menjalankan Grow lebih banyak.

Jika pengulangannya terlalu banyak, Koin bisa menjadi terlalu besar atau keluar dari area yang nyaman dilihat.

Setelah eksperimen, kembalikan Repeat ke 5 karena itu target output minimum.

Debugging dari hasil project

Jika Koin tidak membesar, cek rangkaian dasar. Jika hanya membesar sekali, cek posisi Grow. Jika dialog muncul berulang, cek posisi Say.

Jangan mengubah semua block sekaligus. Perbaiki satu hal, lalu retest dengan Green Flag.

Kebiasaan testing seperti ini membantu siswa memahami sebab dan akibat dari perubahan code.

Output minimum dan challenge

Project selesai jika ada satu Koin, script dimulai dengan Green Flag, Repeat bernilai 5, Grow berada di dalam Repeat, Koin membesar beberapa kali, dan dialog muncul setelah animasi selesai.

Simpan project final dan pastikan tidak ada data finansial pribadi di dalamnya.

Jika semua target utama sudah selesai, challenge-nya adalah menambahkan sprite celengan dan membuat celengan ikut berkata “Tabunganku bertambah!”. Setelah itu lanjutkan ke Checkout Quiz sesuai arahan guru.
